# Codex 답 형식 확인

리뷰 뒤 Codex가 계획을 고쳐 Claude를 부르는 흐름을 만들기 전에, Codex가 AI 메시지 형식(ai-msg v1, AGENTS.md "AI 메시지 형식")으로 답할 수 있는지 실제 PR에서 확인한다. 확인 PR에는 `ai:` 라벨이 없으므로 Codex 답이 형식에 맞아도 자동 흐름은 돌지 않는다.

## 확인할 것

| 항목 | 기준 |
|---|---|
| 표시 줄 | 댓글 원문의 첫 줄(멘션이 있으면 둘째 줄)에 `<!-- ai-msg:v1 ... -->`가 그대로 남는다 |
| 멘션 | `change`는 첫 줄이 `@claude` 한 단어다 |
| 절 | 필수 절이 `### 절 이름`으로 빠짐없이 있고 다른 글이 앞에 없다 |
| 덧붙는 글 | Codex가 끝에 붙이는 `View task →` 같은 줄이 검사를 깨는지 |
| 역할 | 코드를 고치거나 커밋하지 않고 댓글만 단다 |
| 검사 결과 | `scripts/ai/ai-msg.js`의 `validateMessage` 결과 |

## 요청

PR에 메인테이너 계정으로 아래 세 댓글을 하나씩 달고, 앞의 답이 온 뒤 다음을 단다.

1. `change`, 형식을 요청에 적어 줌
2. `answer`, 형식을 요청에 적어 줌
3. `change`, 형식을 적지 않고 AGENTS.md만 따르게 함(실제 자동 요청과 같은 조건)
