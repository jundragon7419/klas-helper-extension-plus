# 계획

KLAS Helper Extension Plus를 v1.0까지 만드는 순서다. 마일스톤 이름은 GitHub 마일스톤과 같다. 날짜는 목표이고, 바뀌면 이 문서를 고친다.

## 0: 기반 (완료)

저장소 규칙, 확장 골격, 검사 체계를 갖췄다.

- 기여 규칙, 이슈와 PR 양식, 브랜치 보호, CI
- WXT와 TypeScript로 만든 확장 골격 (Chrome, Firefox 모두 MV3)
- ESLint, Prettier, Vitest
- 화면 방식과 UI 프레임워크(Preact) 결정

## 1: 데이터 계층 (목표: 2026년 11월 말)

KLAS 내부 API를 확장에서 불러와 마감 목록으로 정리할 수 있는 상태를 만든다. 화면은 만들지 않는다.

- 조사: 세션을 연장하는 요청의 종류, Firefox content script의 KLAS 요청
- 개발 환경: Edge 실행 설정, 저장한 비밀번호와 설정이 유지되는 개발용 프로필
- 테스트 자료: KLAS 응답 수집과 개인정보 제거 스크립트. 학기가 끝나 데이터가 사라지기 전(12월 중순)에 수집한다.
- 날짜 해석: KLAS의 여러 날짜 형식을 항상 한국 시간으로 해석
- KLAS API 조회와 응답 검사. 실패를 세션 만료, 네트워크, JSON 아님, 형식 바뀜으로 구분
- 마감 정리: 네 종류의 목록을 하나의 마감 형식으로 합치고 학기를 고르는 규칙
- 마감 조회: 패널을 열 때 조회하고 같은 KLAS 페이지에서 최근 결과를 다시 씀
- 세션 연장: KLAS 탭이 열려 있는 동안 10분마다, 설정으로 끌 수 있음

## 2: KLAS 탭과 마감 일정 (목표: 2026년 12월 초, v0.1.0)

KLAS 화면 오른쪽의 `<` 버튼으로 여닫는 탭을 만들고, 첫 기능으로 마감 일정을 보여 준다.

- 디자인: 버튼과 탭의 폭과 동작, 좁은 창, 상태 화면(불러오는 중, 비어 있음, 로그인 필요, 실패, KLAS 형식 바뀜, 이전 결과만 있음), 확장 표시 모양, 확장 아이콘. 마일스톤 1과 함께 진행한다.
- Preact 설정과 Shadow DOM 안의 탭
- 마감 목록: 마감 순 정렬, 종류별 필터, 남은 시간, 마지막 확인 시각
- 설정: 세션 연장 끄기
- 확장 표시 공통 부품
- v0.1.0 출시. 메인테이너가 직접 쓰면서 v1.0 범위를 정한다.

## 3: v1.0 범위 기능 (범위는 v0.1.0을 써 본 뒤 결정)

원래 KLAS Helper의 기능과 새 기능 중에서 고른다.

- KLAS 탭 후보: 성적 평점, 석차 기록, 어학 성적, 강의 새 글, 바로가기
- 기존 KLAS 화면 후보: 시간표 시간 표시, 강의 숨기기, 강의계획서 검색 편의, 수강 신청 바로가기, CapsLock 알림, 영상 음량, 다크 모드, 이미지 크기 조절
- 넣지 않는 기능: 2분 쿨타임 제거, 인증 우회, 영상 다운로드, 사용자 대신 제출, KLAS 정보 외부 전송

## 4: 배포 (목표: 2027년 3월 개강 전, v1.0)

- Chrome 웹 스토어, Edge 추가 기능, Firefox 부가 기능 등록
- Firefox 정식 설치에서 사이트 권한이 처음부터 허용되는지 확인. 허용되지 않으면 KLAS 화면에 권한 안내 추가
- 개인정보 처리방침, 스토어 설명과 스크린샷
- 원래 KLAS Helper 사용자를 위한 안내

## 추가 기능 (v1.0 이후)

핵심 기능이 끝난 뒤 이슈로 따로 진행한다.

- 마감 알림. Firefox는 알림 버튼을 지원하지 않으므로 버튼 없이 만든다.
- 툴바 아이콘 배지로 미제출 개수 표시
- 주의가 필요한 기능: 슬라이드 다운로드, 재생 속도 제한 해제, 강의 평가 일괄 입력, 에브리타임 강의 평점. 학교 정책과 서버 부하를 확인한 뒤 정한다.
