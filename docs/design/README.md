# 디자인 시안

KLAS 안 탭과 KLAS 화면에 넣는 요소의 시안이다 (#25). 정한 내용은 `docs/ARCHITECTURE.md`의 "KLAS 탭 디자인"과 "확장 표시"에 있고, 이 폴더의 그림은 그 결정을 눈으로 확인하는 용도다. 그림과 문서가 다르면 문서를 따른다.

| 파일 | 내용 |
|---|---|
| `design_board.png` | 디자인 토큰 미리보기(`npm run tokens:preview`) 전체 화면. 서랍 견본, KLAS 안 요소의 (+) 표시, 대비 검사, 토큰 값 |

#25의 전체 시안은 위 그림에 보관한다. #40에서 정한 날짜별 마감 목록과 조회 상태는 [마감 일정 디자인 보드](deadline_design_board.png)에 모았다. 버튼과 상태 견본은 `npm run tokens:preview`에서도 확인할 수 있다.

그림 속 과목명과 마감은 지어낸 예시다. KLAS 부분은 로고와 실제 화면 없이 자리만 표시했다.
